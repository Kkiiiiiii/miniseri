## 🚀 About The Project

This project is a customized web application and landing page redesign for **miniseri.id**. It focuses on delivering an engaging user experience with seamless responsive layouts, interactive UI components, and media integration tailored for modern content streaming and vertical video formats.

### ✨ Key Features
- **Responsive Landing Page:** Tailored for both desktop and mobile viewports.
- **Vertical Video Integration:** Optimized components for modern short-form and vertical video layouts.
- **Sineas Integration:** Registration and management workflows for creators.
- **Modern UI Components:** Styled efficiently using modern utility-first CSS frameworks and interactive modals.

---

## 🛠️ Tech Stack

This application is built using modern web development tools and frameworks:

- **Backend:** PHP / Laravel
- **Frontend / Styling:** Tailwind CSS / Metronic Tailwind
- **Version Control:** Git & GitHub

## ⚙️ Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
- PHP >= 8.2
- Composer

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rikizhakaria/miniseri.git

2. Navigate to the project directory:
   ```bash
   cd miniseri

3. Install PHP dependencies:
   ```bash
   composer install

4. Copy the enviroment configuration file:
   ```bash
   cp .env.example .env

5. Generate application key:
   ```bash
   php artisan key:generate

6. Run database migration:
   ```bash
   php artisan migrate

7. Start the local development server:
   ```bash
   php artisan serve
